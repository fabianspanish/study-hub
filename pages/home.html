Como expandir

Adicionar novas áreas

A estrutura é modular: novos menus são acrescentados editando o index.html, novas páginas vão para pages/ e novas rotas para js/router.js.

  1. Adicione um item ao menu em index.html dentro da <ul class="menu">. Para um novo grupo (ex: Idiomas), copie um bloco <li data-menu="...">. Para um novo item dentro de um grupo existente, copie uma linha do submenu.
  2. Crie a página HTML em pages/ (ex: pages/idioma-ingles.html). Use as classes cert-hero, cert-main, etc — o estilo é compartilhado.
  3. Registre a rota em js/router.js: adicione '/idioma/ingles': 'pages/idioma-ingles.html' no objeto routes.
  4. Pronto. O hash #/idioma/ingles já carrega a nova página.
Dica

O design das páginas de certificação e da home usa as mesmas classes (cert-hero, cert-toc, module-card, etc). Para manter a consistência, copie a estrutura de pages/cert-az900.html ao criar novas certificações.
